# Shorts из мультфильма «Операция»

Пять вертикальных роликов 1080×1920 (30 к/с) из `cartoon/render/OPERACIYA_1080p.mp4`
(ветка `claude/gifted-cerf-9elsts`). Мат запикан (звук 1 кГц) и замаскирован в субтитрах,
на всех роликах крупные субтитры и заголовок сверху, в конце плашка «Полная версия — на канале».

## Что загружать и как подписать

Публикуйте по одному в день, начиная с самого сильного. Во всех роликах в настройках Shorts
укажите **«Связанное видео» → полный мультфильм**: это кнопка, по которой зритель перейдёт на полную версию.

| # | Файл | Длит. | Название | Откуда |
|---|---|---|---|---|
| 1 | `3_finale.mp4` | 39 с | Задание выполнено. Без потерь 💥 #shorts | 3:05–3:44 |
| 2 | `1_glukh.mp4` | 31 с | Когда в отряде есть Глух 😂 #shorts | 0:59–1:31 |
| 3 | `2_ninja.mp4` | 36 с | Тихо, как ниндзя 🔥 #shorts | 1:35–2:11 |
| 4 | `5_squad.mp4` | 25 с | Худший отряд спецназа 🪖 #shorts | 0:12–0:38 |
| 5 | `4_coffee.mp4` | 13 с | Когда кончился кофе ☕ #shorts | 4:03–4:17 |

**Описание (одно на все):**
```
Худший отряд спецназа получил простое задание. Что могло пойти не так?
Полная версия мультфильма — на канале.
#мультик #юмор #анимация
```

**Настройки при загрузке:**
- Аудитория: «Нет, это видео не для детей».
- Возрастные ограничения: **«Нет»**. В названии, описании и тегах не должно быть мата и «18+».
- Категория: «Юмор» (Comedy).

## Пересборка

Нужны Python 3 и ffmpeg с libass.
```bash
python3 shorts/tools/make_shorts.py OPERACIYA_1080p.mp4 OPERACIYA_final.srt shorts/out shorts/fonts
```
Отрезки, заголовки, ширина кадра и места бипов задаются в начале скрипта (`CLIPS`, `BLEEPS`).
Время мата найдено по огибающей громкости отдельных голосовых дорожек (`cartoon/voice/out/s1e, s2e, s4d.wav`).
