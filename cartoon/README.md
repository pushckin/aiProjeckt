# Мультфильм «Операция: „Хуйню не творить“» (18+)

Короткометражный мультфильм по сценарию из `scenario.txt`, ~4,5 минуты (4:21), 1920×1080, 30 к/с.
Визуальный стиль — по трейлеру **WARDOGS | Gameplay Trailer** (золотисто-дымная палитра, контровой свет,
силуэты ЛЭП и вертолётов, жирный логотип + жёлтый тег + белая рамка). Персонажи — простые мультяшные,
нарисованы и анимированы кодом (SVG-риг + GSAP), всё покадрово снято в MP4.

## Что внутри
| Папка | Что |
|---|---|
| `design/DESIGN.md` | дизайн-система ролика (палитра, шрифты, формы, звук, запреты) |
| `lib/engine.js` | движок: один таймлайн GSAP, камера с параллаксом по слоям, тряска, процедурные эффекты (взрыв, дым, дождь, фейерверк, пена, ядерный гриб…), зерно и грейд |
| `lib/chars.js` | персонажи: риг (ноги, торс, голова, руки с локтями, реквизит), дыхание, моргание, дёргающийся глаз, липсинк по огибающей голоса |
| `lib/sound.js` | звук кодом (Web Audio): взрывы, выстрелы с глушителем, рация, сирена, дождь, музыка по настроениям + приглушение под голос |
| `lib/hud.js`, `lib/sets.js` | титры в стиле трейлера и декорации |
| `scenes/p0…p5_*.html` | шесть частей: титры и перекличка → инструктаж → проникновение → коридор → финал → титры и сцена после титров |
| `voice/` | реплики (`lines.json`), синтез `synth.py` (Piper, офлайн-нейросеть; модели скачиваются отдельно, см. ниже) |
| `tools/` | `step-render.cjs` — покадровый рендер страниц, `mix.cjs` — склейка, дорожка голосов, сведение, субтитры |
| `render/OPERACIYA_1080p.mp4` | готовый мультфильм (1080p, 30 к/с, −14 LUFS); `.srt` — субтитры |

## Пересборка
```bash
# голоса (модели Piper: ru_RU-{denis,dmitri,ruslan}-medium с huggingface.co/rhasspy/piper-voices → voice/models/)
pip install piper-tts soundfile && python3 voice/synth.py
# рендер частей (нужны Node.js, Playwright c Chromium, ffmpeg)
for p in p0_title p1_hangar p2_perimeter p3_corridor p4_finale p5_credits; do FPS=30 node tools/step-render.cjs render/${p%%_*}.mp4 scenes/$p.html; done
# склейка + голос + сведение + субтитры
node tools/mix.cjs
```
Любую часть можно открыть в браузере (`scenes/*.html`) и проиграть кнопкой «▶ Старт» (без голоса — он накладывается при сведении).

## Озвучка
Голоса — **Google AI Studio (Gemini TTS)**, у каждой реплики свой режиссёрский тег подачи (`voice/synth_gemini.py`: CAST и TAG):
Шмидт — Algenib (хриплый шёпот, рыдания, истерика), Грейвс — Orus через «рацию», Бублик — Fenrir (фанатичный крик),
Лаки — Puck, Глух — Sadachbia (орёт как глухой), Босс — Alnilam, наёмник — Zubenelgenubi, диктор трейлера — Charon.
Бесплатный тариф даёт 10 запросов в сутки на модель, поэтому `voice/synth_batch.py` озвучивает персонажа одним запросом и режет по паузам;
каждая реплика проверена расшифровкой. Ключ берётся из `GEMINI_API_KEY` или `~/.config/watch/.env` и в репозиторий не попадает.
Резервная офлайн-озвучка Piper — `voice/synth.py`.

Стиль сверен с разбором трейлера видеомоделью Gemini: жёлтые плашки и белый жирный гротеск, блочные глитч-переходы,
RGB-расслоение при прицеливании, чёрно-белый драматический момент, глитч-сборка логотипа.
